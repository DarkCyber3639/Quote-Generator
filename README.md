# Random Quote Generator

A simple Python application that generates random motivational quotes.

## Features

- **100+ Quotes**: Collection of inspirational quotes
- **Single Quote**: Get one random quote at a time
- **Multiple Quotes**: Retrieve multiple random quotes without repetition
- **Interactive Menu**: Easy-to-use command-line interface
- **No Dependencies**: Pure Python, nothing to install

## Installation

### Prerequisites
- Python 3.6 or higher

### Clone the Repository
git clone https://github.com/YOUR\_USERNAME/quote-generator.git
cd quote-generator

### Usage:
python quote_generator.py

### Adding more Quotes 
To add more quotes, simply add them to the quotes list in quote_generator.py.
